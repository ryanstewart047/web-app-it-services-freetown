## 2. Store Descriptions

### Short Description (up to 132 chars)
Professional image forensic analysis, Error Level Analysis (ELA), AI deepfake detection, and EXIF metadata extraction in your browser.

### Detailed Description
BridgeTech ForensicLens is an all-in-one image forensic analysis and synthetic deepfake detection suite for journalists, researchers, cybersecurity analysts, and digital creators.

🔍 KEY FEATURES:
• Error Level Analysis (ELA): Detect digital manipulations, cloned regions, cut-and-paste splices, and resaving compression anomalies in real time.
• AI & Deepfake Detector: Uncover frequency domain signatures, diffusion grid patterns, and synthetic artifacts generated by Midjourney, DALL-E 3, Stable Diffusion, Flux, and GANs.
• Deep EXIF & Hardware Metadata: Extract camera model, lens parameters, shutter speed, ISO, software modification history (Photoshop, Canva, GIMP), and GPS geolocation.
• Luminance & Color Channel Splitter: Verify lighting direction, shadow consistency, and isolate RGB channels with solarisation and high-pass edge filters.
• Cryptographic Audit Dossiers: Compute image SHA-256 hashes and download official, court/journalism-admissible forensic verification reports.
• 1-Click Right-Click Inspection: Right-click any image across the web to launch instant side-panel analysis without switching tabs.

🔒 PRIVACY & SECURITY FIRST:
All forensic processing (ELA, channel splitting, EXIF parsing) executes 100% locally in your browser memory. No private images are uploaded or stored on external servers.

## 3. Permissions Justifications (Required by Review Team)

| Permission | Plain-English Reason for Chrome/Edge Reviewers |
|---|---|
| `sidePanel` | Displays the forensic analysis interface, ELA heatmaps, and EXIF metadata alongside web content without interrupting browsing. |
| `contextMenus` | Adds a right-click option ("Inspect with BridgeTech Forensics") allowing users to analyze web images immediately. |
| `storage` | Stores user preference settings, local daily usage counts, and Pro license key securely. |
| `activeTab` | Allows the extension to read the targeted image element when explicitly selected by the user via the context menu. |
| `scripting` | Enables scanning open pages to detect images when requested by the user. |
| `host_permissions: <all_urls>` | Required to extract images and compute Error Level Analysis on web images across arbitrary domains where users encounter suspicious media. |
