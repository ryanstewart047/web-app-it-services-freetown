## 🚀 Step-by-Step: Import Your First Article

### Step 1: Open Both Files
1. **Local file**: `blog-articles-preview.html` (already downloaded)
2. **Web page**: https://www.itservicesfreetown.com/blog/admin

### Step 2: Select Article
In `blog-articles-preview.html`:
```
Click → [Computer Repair Services] button
```
You'll see the article load with title and content

### Step 3: Copy Title
```
Click → [📋 Copy Title] button
```
✓ Copied: "Complete Guide to Computer Repair Services in Freetown, Sierra Leone"

### Step 4: Go to Blog Admin
In blog admin page:
```
1. Login with admin credentials
2. Paste title in "Post Title" field
3. Keep author as "BridgeTech IT Services"
```

### Step 5: Switch to HTML Preview Mode
```
Click → [👁️ HTML Preview] button (top right of content area)
```
The interface changes to split-screen!

### Step 6: Copy HTML Content
Back in `blog-articles-preview.html`:
```
Click → [📋 Copy HTML Content] button
```
✓ Copied: Full HTML article content

### Step 7: Paste in HTML Source
In blog admin (left pane):
```
1. Click in the HTML Source textarea
2. Paste (Ctrl+V or Cmd+V)
3. Watch the preview appear on the right!
```

### Step 8: Review Preview
Look at the right pane:
```
✓ Headers are properly sized
✓ Paragraphs are spaced nicely
✓ Lists show with bullet points
✓ Bold text is emphasized
✓ Everything looks good!
```

### Step 9: Apply Changes
```
Click → [✓ Apply Changes] button (top of left pane)
```
✓ Success! HTML saved to content field

### Step 10: Publish
```
Scroll down → Click [Publish Post] button
```
🎉 Article published to your blog!

### Step 11: Repeat
Go back to Step 2 for the next article!

## 🎯 What Each Button Does

### Top Header Buttons
```
[📋 Copy HTML]  → Copies raw HTML code to clipboard
[📋 Copy Text]  → Copies plain text (no HTML tags)
```

### Left Pane Button
```
[✓ Apply Changes] → Saves HTML edits to content field
                    Allows switching back to Rich Text mode
```

### Bottom Buttons
```
[Preview]       → Shows how post will look when published
[Publish Post]  → Publishes article to your blog (live!)
```

### Mode Toggle Buttons
```
[📝 Rich Text]   → Switch to WYSIWYG editor
[👁️ HTML Preview] → Switch to split-screen editor (ACTIVE)
```

## 💡 Common Questions

### Q: Can I switch between modes without losing content?
**A:** Yes! Content is automatically synced when you switch modes.

### Q: What if I make a mistake in the HTML?
**A:** The preview shows exactly what will render. Fix errors in the left pane.

### Q: Do I need to know HTML?
**A:** Not really! Just copy/paste from your articles. The preview shows results.

### Q: Can I edit the HTML after pasting?
**A:** Yes! Edit in the left pane, see changes in the right pane instantly.

### Q: What if the preview looks wrong?
**A:** Check the HTML source for typos or missing closing tags (e.g., `</p>`).

### Q: Can I use Rich Text mode after importing?
**A:** Yes! Click "Apply Changes" first, then switch to Rich Text mode.
